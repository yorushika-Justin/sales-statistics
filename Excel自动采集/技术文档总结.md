## 1. 项目全景

一句话：**驱动本机 Edge 自动登录思迅供应商平台（OCR 验证码）→ 按日期查「供应商日销售汇总」→ 导出 Excel → 自动喂 `销售汇总.exe` → 双 PNG 落相册目录**。

三种使用形态（共享同一核心 `collect.js`）：

| 形态 | 入口 | 特点 |
|---|---|---|
| 命令行（母本） | 桌面「销售一键采集」/ `一键采集.bat` | 查昨天（或 `--date`），黑窗进度，双击即用 |
| **图形界面版** | 桌面「销售采集界面」/ `图形界面版\启动界面.bat` | 浏览器界面：**选任意日期**、阶段指示灯、实时日志、结果 PNG 预览 |
| 开始菜单磁贴 | 「销售一键采集」右键→固定到开始屏幕 | 一次性手动操作 |

## 3. 核心机制速查

| 机制 | 要点 | 出处 |
|---|---|---|
| 登录 | 拦 `VerifyCode.ashx` **原图字节** → rapidocr 识别（截图版识别率低）；失败自动刷新重试 ≤5 | 技术文档 §4 |
| 查询日期 | 母本：`--date YYYY-MM-DD` 或 `今天−date_offset`；界面版日期控件 | 技术文档 §5 |
| 查询完成判据 | EasyUI 加载遮罩 `.datagrid-mask` + 3 秒宽限 + 条数出现即完成（同条件重跑合法成功） | 技术文档 v1.2 |
| 门店校验 | 只校验「条件记忆」值含 `store_keyword`，不匹配即报错（不自动选店） | 设计文档 §6 |
| 0 行数据 | 中止不导出（数据未同步），提示重跑 | 设计文档 §6 |
| Excel 校验 | 0 字节/行数异常**拦截**，不流入汇总 | v1.2 |
| PNG 核验 | `mtime ≥ 任务启动时间`，防历史残留假阳性 | v1.2 |
| 进程清理 | Ctrl+C/取消 → `taskkill /T /F` 树杀（防孤儿 Edge） | v1.2 / 方案 §8 |

| 字段 | 含义 | 默认 |

| `store_keyword` | 门店校验关键字 | 羊森东门里店 |

| `summary_mode` | `exe`（默认）/ `py`（排错） | exe |

## 7. 关键经验（踩坑沉淀）

1. **纯 HTTP 登录不可行**（验证码通过后服务端 500）→ 一律 Playwright 真浏览器
2. **验证码 OCR 必须拿服务端原图字节**，不要截页面元素
3. **编码三坑**：PowerShell `Set-Content` 默认 GBK 毁 config；中文 bat/脚本名在 cmd 下 GBK/UTF-8 互掐（入口一律 ASCII，中文提示由 Node 出）；汉字跨 stdout chunk 要 `setEncoding`
4. **路径解析要锚定 `(N 字节)`**，否则 `Program Files (x86)` 括号截断
5. **同条件重跑是合法成功**，不能用"结果文本必须变化"当完成判据
6. Windows 杀进程必须 `taskkill /T /F` 树杀，`child.kill()` 会漏 Edge

## 8. 已知取舍与限制

- 密码明文存 config（本机场景；DPAPI 属 v2）
- OCR/汇总用同步子进程（阶段内无并发页面交互，刻意取舍）
- 单日单店；多店/多日/自动选店/定时任务属 v2 候选
- 汇总失败会弹 tkinter 错误框需人工关（采集侧 120s 超时兜底）
- 昨天数据未同步 → 0 行中止，需人工重跑
- `%TEMP%\playwright*` 在取消强杀时可能残留（无害）；服务启动时读配置快照，运行中改动需重启
