## 一、背景与范围界定

### 1.1 本轮要做什么

把现有的**手机端程序**（`程序端\`，Render 云部署，手机上传 xls/xlsx → 生成品牌汇总 + 品名明细 PNG → 预览 / 保存到手机）做一次**完善**：修掉审查发现的缺陷 + 提升手机端体验。

### 1.2 本轮明确**不做**什么（已讨论并否决，记录备查）

用户希望"在手机上实现 `Excel自动采集\图形界面版` 那样的**远程触发采集**"，经评估后**放弃**，理由：

| 判断 | 说明 |
|---|---|
| 采集无法离开 Windows PC | Playwright 驱动本机 Edge、`销售汇总.exe`、输出到本机图片目录，全都依赖那台机器 |
| PC 不长期开机 → 功能不成立 | 手机想用的那一刻 PC 大概率是关着的，"远程触发"做出来绝大多数时候点下去只会连不上 |
| 附加负担不成比例 | 公司网络装组网工具、ERP 同账号单点登录互踢、公网访问必须加口令、电源与自启策略…… |
| 结论 | **不做远程触发采集。** 现有"手机上传 xls 出图"这条线继续用，本轮只把它打磨好 |

> 若将来想解决"人不在电脑旁时看数据"，可另议"PC 开机时自动采集 + 结果同步到手机"，与本轮无关。

### 1.3 现有架构（基线）

```
手机浏览器 ──HTTPS──▶ Render 免费层（Linux 容器）
                          │
                     程序端\web_server.py   ← Flask，host=0.0.0.0，PORT 读环境变量
                          │
                     程序端\汇总脚本.py     ← 适配层：mock tkinter + 覆盖 OUTPUT_DIR/FONT_PATH
                          │
                     原版 汇总脚本.py        ← 读 xls/xlsx → 两张 PNG（不改动）
                          │
                     /opt/render/output/sales/<日期>/          ← Render **临时磁盘**
```

| 路由 | 作用 |
|---|---|
| `GET /` | 内嵌单页前端（HTML/JS/CSS 全内联） |
| `POST /upload` | 接收 xls/xlsx（≤10MB）→ 生成两张 PNG → 返回预览/下载 URL |
| `GET /download/<路径>` | `?dl=1` 触发下载，否则内联显示 |
| `GET /health` | 健康检查 |

## 二、审查发现的问题

编号规则：`P-x`（Program 端）。等级参考前几轮：**高**＝会直接咬到使用者，**中**＝隐患，**低**＝体验。

### A 组 — 会咬到你实际使用的（建议必修）

| 编号 | 等级 | 问题 | 现状与后果 |
|---|---|---|---|
| **P-1** | 高 | `<input type="file">` 处理完未重置 `value` | **手机上同一个文件选第二次完全没反应**（`change` 事件不触发），会让人以为程序坏了 |
| **P-2** | 高 | 结果区用 `status.appendChild(preview)` 只追加不替换 | 连传两次，新旧两组图叠在一起，页面越用越长 |
| **P-3** | 高 | 超 10MB 时 Flask 返回 **HTML 错误页**，前端 `.json()` 解析崩 | 页面显示 `请求失败: Unexpected token '<'`，完全看不懂发生了什么 |
| **P-4** | 高 | 出错只返回 `类型: 消息`，完整堆栈只在服务器 `/tmp/sales_web_error.log` | 看不到行号，与 2026-08-02 那次 `IndexError` 排查时一样的困境（当时就得靠临时加调试端点） |
| **P-5** | 中 | 文案写死"将 .xls / .xlsx 文件**拖入**此处" | 手机没有拖拽，属于误导；小屏下卡片 `padding:40px` 偏大，触控目标偏小 |
| **P-6** | 中 | Render 免费层冷启动约 30 秒，页面**毫无提示** | 首屏空白像卡死，用户会重复点、甚至以为服务挂了 |

### B 组 — 看不见但会咬人的隐患（建议必修）

| 编号 | 等级 | 问题 | 现状与后果 |
|---|---|---|---|
| **P-7** | 中 | `/download` 路径穿越检查用**字符串前缀比较**：`filepath.startswith(os.path.normpath(OUTPUT_DIR))` | 同前缀的兄弟目录可被绕过（`/root/output/sales_evil/...` 会通过检查）；且**未限制只能下 PNG** |
| **P-8** | 中 | `process_xls()` 在运行中**临时改写全局** `汇总脚本.FONT_PATH` 再恢复 | Flask `threaded=True` 下**线程不安全**：并发上传时线程 A 可能读到线程 B 改过的值/恢复后的值 |
| **P-9** | 中 | `requirements.txt` 四个包**全未锁版本** | Render 构建缓存过期会拉到新版依赖 → 可能重现"本地好好的、线上炸"（2026-08-02 排查记录里已列为怀疑项） |
| **P-10** | 低 | `/health` 返回 `output_dir` 与 `font_path` 服务器绝对路径 | 已实测线上确实在裸奔输出路径，属信息泄露；健康检查只需要 200 |

### C 组 — 需你拍板的新增项

| 编号 | 等级 | 项 | 说明 |
|---|---|---|---|
| **P-11** | 中 | **访问口令** | 现在**任何人拿到网址都能上传/看图**。加一层口令后，手机首次带 `?k=<口令>` 访问即种 Cookie，之后免输 |
| **P-12** | 低 | **历史记录 + 图片缓存** | 页面能看到最近生成的图，不用重复上传；并给 PNG 加缓存头，省手机流量 |
| **P-13** | 低 | **界面美化** | 沿用清爽卡片风，主色 `#0E90D8`（与桌面图标、图形界面版一致），标题图标 + 按钮状态 + 等待指示 |

## 三、修复方案

### 3.1 A 组

**P-1 重置文件选择框**
- 改法：`change` 回调读取后立即 `e.target.value = ''`（放在 `uploadFile()` 之后；失败路径也要重置，用 `finally` 语义）。
- 验证：本地浏览器连续两次选**同一个文件**，第二次必须正常发起上传。

**P-2 结果区改为替换**
- 改法：状态条（`.status`）与结果区（新增 `#result`）分离；每次上传开始先 `result.innerHTML = ''`，成功后再填内容。
- 验证：连传两次，页面只保留最后一次的两张图。

**P-3 异常一律走 JSON**
- 改法：
  - 服务端新增 `@app.errorhandler(413)` → `{"success": false, "message": "文件超过 10MB 限制，请压缩后再传"}`；再补 `@app.errorhandler(500)` 兜底 JSON。
  - 前端 `fetch` 改为**先取 `response.text()`，再尝试 `JSON.parse`**；解析失败时按 HTTP 状态码给中文兜底文案（如 `服务异常（HTTP 413）`）。
- 验证：构造 >10MB 的假 xls 上传，页面必须显示中文提示，**不得**出现 `Unexpected token`。

**P-4 错误可定位**
- 改法：
  - 服务端异常分支生成短 `error_id`（如 `e7c1a2f4`），完整堆栈仍写服务器日志（**前缀带上同一个 error_id**，便于对照），响应体返回：
    ```
    { success:false, message:"IndexError: array index out of range",
      detail:"文件 \"汇总脚本.py\", line 214, in read_xls", error_id:"e7c1a2f4" }
    ```
    `detail` 只取 traceback **最后一行**（文件 + 行号 + 函数名），不返回整段堆栈。
  - 前端错误状态下增加「查看详情」折叠区，展示 `detail` 与 `error_id`。
- 验证：故意传一个**损坏的 xls**（比如把 txt 改名成 .xls），页面必须能看到带行号的详情。

**P-5 手机端文案与排版**
- 改法：
  - JS 判断触屏（`navigator.maxTouchPoints > 0` 或 `matchMedia('(pointer: coarse)')`）：触屏显示「**点击选择文件**」，非触屏保留拖拽文案 + 拖拽事件。
  - CSS 增加 `@media (max-width: 480px)`：卡片 `padding` 收到 `20px`；主按钮高度 ≥ 44px；标题字号下调。
- 验证：本地 Edge 开发者工具切移动模拟（iPhone/安卓尺寸）逐项核对。

**P-6 冷启动提示**
- 改法：页面加载即 ping `/health`（`AbortController` 3 秒超时）。超时未回 → 顶部显示「**服务器正在唤醒**（免费层休眠，约 30 秒），请稍候…」并转圈；一旦响应即撤下。
- 说明：本地无法真实模拟 Render 休眠，用"临时把 `/health` 人为延时"或"断网"两种方式验证两个分支。
- 附带（低成本的"等待感"）：`/upload` 期间显示已等待秒数。

### 3.2 B 组

**P-7 收紧 `/download`**
- 改法：
  ```python
  base = os.path.realpath(OUTPUT_DIR)
  target = os.path.realpath(os.path.join(base, filename))
  if target != base and not target.startswith(base + os.sep):
      return jsonify(...), 403
  if not target.lower().endswith('.png'):
      return jsonify(...), 403
  ```
  用 `realpath` + `base + os.sep` 边界（避免 `sales_evil` 这类同前缀绕过），并限制扩展名为 `.png`。
- 验证：请求 `/download/../sales_x/a.png`、`/download/../../etc/passwd`、`/download/<日期>/x.txt` → 全部 403。

**P-8 消除字体全局改写**
- 改法：在 `程序端\汇总脚本.py` 模块加载时**一次性**设置 `汇总脚本.FONT_PATH = FONT_PATH`；删除 `process_xls()` 里 6 行"临时覆盖 + finally 恢复"。因 `FONT_PATH` 运行期不变，语义等价且**彻底消除线程竞态**。
- 验证：并发（≥5 个线程）同时上传不同 xls，全部成功、图内中文字体正确。

**P-9 锁定依赖版本**
- 改法：
  ```
  flask==3.1.3
  xlrd==1.2.0
  openpyxl==3.1.5
  Pillow==12.1.1
  ```
  （这四个版本即本机实测通过的组合）
- 验证：本地按此组合跑通完整上传；部署后访问一次线上确认正常。

**P-10 精简 `/health`**
- 改法：只返回 `{"status":"ok"}`；`output_dir` / `font_path` 仅在**启动日志**里打印（服务器侧可见，不外泄）。若 P-11 采纳，可另加受口令保护的 `/api/info`。
- 验证：本地与线上 `curl /health` 均只见 `status`。

### 3.3 C 组（可选，逐项确认）

**P-11 访问口令**
- 设计：
  - 口令从**环境变量** `ACCESS_TOKEN` 读取（Render 面板配置）。**未设置时行为完全不变**（默认关闭，避免部署即锁死）。
  - 启用后：手机首次访问 `https://<域名>/?k=<口令>` → 校验通过种 Cookie（`HttpOnly`、`Secure`、`SameSite=Lax`、30 天）→ 之后免输；未通过则返回一个极简口令输入页。
  - 保护范围：`/`、`/upload`、`/download/*`；**不保护** `/health`（Render 健康检查用）。
  - 用 `hmac.compare_digest` 比较，避免时序侧信道。
- **需要你做的**：在 Render 面板手动加环境变量（我没有 Render 账号，这一步只能你来；我给出逐步操作说明）。
- 验证：本地起服务设 `ACCESS_TOKEN` → 无 Cookie 请求 403/输入页，带正确口令通过，错误口令拒绝。

**P-12 历史记录 + 图片缓存**
- 设计：
  - 新增 `GET /history`（或首页折叠区）：列出输出目录下最近的日期文件夹与其中 PNG（按修改时间倒序，取最近 10 条），点击即内联预览 + 保存按钮。
  - `/download` 响应加 `Cache-Control: public, max-age=86400`（配合口令 Cookie，仍受保护），手机重复看图不再走流量。
- **必须知道的前提**：Render 免费层磁盘是**临时的**——重新部署或容器重启后历史清空。所以这是"本次部署周期内"的历史，**不是长期存档**。要不要做，取决于你认不认这个限制。
- 验证：本地生成 3 个日期目录，列表顺序与预览正确。

**P-13 界面美化**
- 设计：主色 `#0E90D8`；标题左侧加小图标（内联 SVG 或 emoji，不引外部资源，保持"完全离线可用"）；按钮三态（默认/处理中/禁用）；结果卡带阴影与圆角。
- 验证：移动模拟视图截图确认。
