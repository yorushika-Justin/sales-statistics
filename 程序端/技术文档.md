# 程序端（Render 云部署）技术文档

## 1. 概述

将销售汇总工具部署到 Render.com 免费云平台，实现**手机端上传 xls/xlsx → 生成 PNG → 下载到手机**。

- **部署地址**: `https://sales-statistics-rdle.onrender.com`
- **代码仓库**: `https://github.com/yorushika-Justin/sales-statistics`
- **版本**: v1.1（2026-09-29）
- **费用**: 全部免费（Render Free Tier）

## 2. 架构

```
手机夸克浏览器
    │
    ▼
Render.com（云服务器，免费层）
    │
    ├─ 程序端/web_server.py  ← Flask 入口
    ├─ 程序端/汇总脚本.py    ← 适配层（mock tkinter + 覆盖配置）
    ├─ 程序端/msyh.ttc       ← 微软雅黑字体（19MB）
    └─ 汇总脚本.py            ← 原版核心逻辑（不修改）
```

## 3. 文件清单

| 文件 | 说明 |
|---|---|
| `程序端/web_server.py` | Flask 服务，路由 /、/auth、/upload、/download、/history、/health |
| `程序端/汇总脚本.py` | 适配层，从原版导入核心函数，覆盖 OUTPUT_DIR/FONT_PATH，mock tkinter |
| `程序端/msyh.ttc` | 微软雅黑字体，嵌入仓库（Render 无法 apt-get） |
| `requirements.txt` | Python 依赖：flask、xlrd、openpyxl、Pillow |
| `Procfile` | Render 启动命令：`web: python 程序端/web_server.py` |
| `render.yaml` | Render 配置（部分字段手动设置更准确） |

## 4. 关键设计

### 4.1 适配层模式（不修改原版）

`程序端/汇总脚本.py` 通过以下方式复用原版逻辑：

1. `sys.path.insert` 将项目根目录加入 import 路径
2. `from 汇总脚本 import read_xls, draw_table, ...` 导入核心函数
3. 覆盖模块级变量（OUTPUT_DIR、FONT_PATH）
4. 提供 `process_xls()` 封装入口

### 4.2 tkinter Mock

原版 `汇总脚本.py` 顶部 `import tkinter`，Linux 服务器无 Tk 库会报错。适配层在导入前 mock：

```python
if os.name != 'nt':
    sys.modules['tkinter'] = _tk_mock
    sys.modules['tkinter.messagebox'] = _tk_mock.messagebox
```

### 4.3 字体处理

Render 免费层无 sudo 权限，无法 `apt-get install fonts-wqy-zenhei`。解决方案：将 `msyh.ttc`（19MB）直接放入仓库，`FONT_PATH` 指向仓库内文件。

### 4.4 下载机制

- `/download/<path>` 路由：`?dl=1` 触发下载，否则内联显示（给 `<img>` 用）
- 前端：图片预览 + "保存" 按钮（`?dl=1`）
- 安全：路径穿越检查（`normpath` + `startswith`）

### 4.5 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `PORT` | 5000 | Render 自动分配，无需手动设 |
| `OUTPUT_DIR` | `~/output/sales` | PNG 输出目录 |
| `FONT_PATH` | 仓库内 `msyh.ttc` | 字体路径 |
| `ACCESS_TOKEN` | **未设置** | v1.1 新增。设置后启用访问口令（详见 4.6）；**不设置则服务行为与 v1.0 完全一致** |

### 4.6 访问口令（v1.1 新增）

面向公网的轻量保护，默认关闭：

- 读环境变量 `ACCESS_TOKEN`。**为空 = 功能关闭**（避免部署后把自己锁在门外）
- **支持中文/任意字符口令**（内部先编码为 bytes 再比较；早期实现直接比较字符串会让中文口令 500）
- 启用后三种进入方式：
  1. `https://<域名>/?k=<口令>` —— 校验通过后种 Cookie 并 302 跳到干净地址（口令不留在地址栏）
  2. 口令页表单 `POST /auth`
  3. 已持 Cookie 直接访问
- Cookie：`HttpOnly` + `SameSite=Lax` + 30 天；线上经 Render 代理（`X-Forwarded-Proto: https`）自动带 `Secure`
- 比较用 `hmac.compare_digest`（防时序侧信道）；Cookie 存的是口令的 SHA-256 派生值，不是明文
- 保护范围：`/`、`/upload`、`/download/*`、`/history`；**`/health` 不保护**（Render 健康检查）
- 未通过时：浏览器导航请求返回口令页（401），接口请求返回 401 JSON

### 4.7 错误可定位（v1.1 新增）

上传失败时响应体：

```json
{ "success": false,
  "message": "XLRDError: Unsupported format, or corrupt file...",
  "detail": "book.py:1272 (bof_error) → XLRDError: ...",
  "error_id": "f919a475" }
```

- `detail` = 完整堆栈里**属于本项目**的最内层帧（`文件:行号(函数)`）+ 异常，前端有「查看详情」折叠区
  - 刻意优先项目代码而非第三方库内部帧：实测损坏 xls 给出的是 `汇总脚本.py:306 (read_xls)`，而不是 xlrd 内部的 `book.py:1272`
- 比较口令用 `_safe_eq()`（先编码成 bytes 再 `hmac.compare_digest`）—— 直接比较非 ASCII 字符串会抛 `TypeError` 导致中文口令 500
- `error_id` 同时写进服务器日志（`/tmp/sales_web_error.log`），可用编号直接检索完整堆栈
- 超 10MB 由 `errorhandler(413)` 返回中文 JSON；前端**先取 text 再尝试 parse**，服务端返回 HTML 也不会崩

### 4.8 最近生成与缓存（v1.1 新增）

- `GET /history`：列出输出目录下最近 10 个日期文件夹内的 PNG，按时间倒序最多 20 条，返回 `{date, name, url, time, size_kb}`
- 时间按**北京时间**显示（容器时区是 UTC）
- `/download` 用**协商缓存**：`Cache-Control: no-cache, private` + ETag。每次向服务器校验，内容未变返回 **304**（照样省流量），变了立刻拿到新图
  - **为什么不强缓存**：图片 URL 按日期固定命名（`/download/<日期>/<日期>.png`），同一天重新上传后 URL 不变；若用 `max-age`，浏览器在有效期内不请求也不重校验，手机就会一直显示、甚至保存**旧图**（这是 v1.1 开发中真实踩到的回归 R-1，已修正）
- **注意**：Render 免费层磁盘是临时的，重新部署/容器重启即清空 —— 这是"本次部署周期内"的历史，不是长期存档

## 5. 用户体验

### 手机端流程（v1.1）

1. 手机浏览器打开 `https://sales-statistics-rdle.onrender.com`
   - 若已启用口令：首次带 `?k=<口令>` 或在口令页输入，之后 30 天内免输
2. 点「点击选择文件」→ 选 xls/xlsx（手机端不显示"拖入"字样）
3. 等待处理
   - 首次冷启动约 30 秒，页面显示「服务器正在唤醒…」
   - 处理中显示已等待秒数
4. 页面显示品牌汇总 + 品名明细图片预览
5. 点「保存品牌汇总」「保存品名明细」→ 存到手机
6. 底部「最近生成」查看最近处理过的图片（容器重启后清空，属正常）
7. 出错时页面给出 `文件:行号(函数)` + 错误编号，可直接对照服务器日志

### 限制

- 冷启动：Render 免费层 15 分钟不活跃后休眠，首次访问约 30 秒
  - 页面上的「服务器正在唤醒」提示**只在页面已加载后**才起作用（检测的是"打开之后服务变得不可达"）
  - **首次打开时的 30 秒白屏消不掉**（那时首屏 HTML 本身还没到，JS 无从运行）。要彻底消除需**保活**：用免费 uptime 监控每 5 分钟 GET 一次 `/health`；注意免费层 750 实例小时/月，单服务 24/7 约需 730 小时
- 文件大小：10MB 限制（`MAX_CONTENT_LENGTH`），超限返回中文 JSON 提示
- 速度：免费层 CPU 有限，大文件处理较慢
- **磁盘临时**：重新部署/容器重启后「最近生成」清空，生成的 PNG 不留存
- **并发串行**：v1.1 起处理过程加锁串行化（防止并发写坏同名图片），多人同时上传会排队
- **口令无速率限制**：启用口令请用足够长的随机串（建议 20 位以上）

## 6. Render 免费层说明

- **750 小时/月** — 足够单服务 24/7 运行
- **无硬性到期日** — 政策可能调整，需关注官方
- **15 分钟休眠** — 不活跃自动休眠，请求触发唤醒
